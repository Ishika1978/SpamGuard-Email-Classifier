# SpamGuard — Spam Email Classifier

A Flask-based machine-learning application that classifies email content as **spam** or **legitimate (ham)**. It compares Multinomial Naive Bayes and a probability-calibrated Linear SVM using TF-IDF features.

## Dataset

This project uses the Apache SpamAssassin Public Mail Corpus:
https://spamassassin.apache.org/old/publiccorpus/

The extracted email files are organized under:
- `dataset/raw/easy_ham/`
- `dataset/raw/easy_ham_2/`
- `dataset/raw/spam/`

The project prepares these files into `dataset/email_dataset.csv`.

## Windows setup

Run these commands from the project folder in PowerShell:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python prepare_dataset.py
python train.py
python app.py
```

Open http://127.0.0.1:5000

## Machine-learning workflow

1. Parse raw email files and extract subject/body text.
2. Convert text to TF-IDF unigram and bigram features.
3. Train Multinomial Naive Bayes and Linear SVM.
4. Calibrate Linear SVM probabilities using cross-validation so the app can show a confidence estimate.
5. Compare models on a stratified 20% held-out test set and select the model with the best spam F1-score.
6. Use the selected model in the Flask web application.

## Evaluation

Metrics are generated from the dataset on the user's machine and saved to `models/metrics.json`. They are not hardcoded. The displayed confidence is a calibrated model probability, not a guarantee that a prediction is correct.

## Limitations

The corpus is historical and may not represent current spam campaigns. This is an educational project, not a production email security gateway. Follow the corpus terms and attribution on the official Apache SpamAssassin page.
